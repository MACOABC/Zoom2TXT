# Política de seguridad

## Versiones

Las correcciones se aplican a la última versión publicada.

## Reportar una vulnerabilidad

No abras un issue público si el informe contiene credenciales, URLs de grabaciones, identificadores de cursos o datos académicos. Utiliza **Security → Report a vulnerability** en GitHub. Si esa opción no está disponible, contacta al mantenedor desde su perfil de GitHub sin adjuntar secretos inicialmente.

Incluye una descripción, impacto, pasos mínimos de reproducción y versión afectada. Sustituye todo token, correo, cookie, ID o URL real por valores ficticios.

## Secretos comprometidos

Eliminar un archivo del último commit no invalida una credencial. Revoca primero el token o contraseña, limpia el historial y vuelve a ejecutar el análisis completo antes de publicar.
