# Metodología de métricas

Las cifras del README describen el flujo personal observado por el autor antes y después de Zoom2TXT. No representan un estudio controlado ni prometen el mismo resultado en todas las instituciones.

## Interacciones manuales

El proceso anterior implicaba, según el caso, abrir el campus, entrar al curso, localizar Zoom, buscar la grabación, elegir el archivo correcto, descargarlo, abrir YouTube Studio, iniciar y configurar la subida, esperar el procesamiento, abrir subtítulos, elegir idioma, descargar, convertir y organizar el resultado. El conteo observado fue de aproximadamente **15–18 acciones**.

Con Zoom2TXT, la intervención habitual se reduce a:

1. Buscar clases.
2. Revisar la selección.
3. Confirmar el procesamiento.

Las esperas de red y de YouTube continúan existiendo, pero no requieren interacción constante.

## Tiempo

- **Antes:** aproximadamente 10–20 minutos de intervención por clase, sin contar esperas pasivas largas.
- **Ahora:** aproximadamente 1–3 minutos de intervención por clase, más tiempo automático de descarga, subida y subtítulos.

La velocidad total depende del tamaño del video, conexión, carga de YouTube y disponibilidad de subtítulos. Por eso el README distingue **intervención humana** de **duración total del pipeline**.

## Evidencia técnica

- Suite automatizada con datos sintéticos y tráfico HTTP real bloqueado.
- Estados persistentes para continuar descargas, subidas y subtítulos.
- Modo demo reproducible sin acceso institucional.
- Uso real del flujo por el autor; no se afirma adopción externa sin evidencia documentada.
