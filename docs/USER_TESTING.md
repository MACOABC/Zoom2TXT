# Plan de pruebas con usuarios

Estado: **pendiente de ejecución**. El proyecto no afirma todavía haber sido validado por cinco estudiantes.

## Objetivo

Comprobar si una persona nueva puede entender el flujo, configurar sus propias cuentas, recuperar un trabajo interrumpido y encontrar el TXT sin ayuda del autor.

## Protocolo sugerido

1. Reclutar entre tres y cinco estudiantes con autorización para acceder a sus propias grabaciones.
2. Entregar únicamente la Release y `LEEME.txt`.
3. Pedir que ejecuten el modo normal y completen una clase propia; no solicitar ni registrar sus credenciales.
4. Medir tiempo de configuración, tiempo de intervención, errores encontrados y pasos que necesitaron explicación.
5. Recoger comentarios sin capturas, nombres de cursos, enlaces ni transcripciones reales.
6. Convertir cada problema reproducible en un issue anonimizado y volver a ejecutar las pruebas automatizadas tras corregirlo.
