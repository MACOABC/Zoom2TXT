## Descripción corta de GitHub

> Automatización de grabaciones académicas: Blackboard → Zoom → YouTube → TXT, con OAuth por usuario, recuperación y 148 pruebas.

## Entrada para CV

> **Zoom2TXT — Python, PySide6, OAuth 2.0, YouTube Data API**<br>
> Diseñé una aplicación de escritorio que automatiza el descubrimiento de grabaciones académicas y la obtención de transcripciones. En mi uso real, redujo un flujo de aproximadamente 15–18 interacciones a una búsqueda, revisión y confirmación, con 148 pruebas automatizadas y recuperación de trabajos interrumpidos.

## Entrada para LinkedIn

> Construí Zoom2TXT para eliminar un proceso académico repetitivo: localizar una grabación, distinguir el MP4 del audio separado, descargarla, subirla temporalmente, esperar subtítulos y organizar el TXT final. La aplicación usa credenciales propias de cada usuario, persiste el avance y evita repetir descargas o subidas ya confirmadas. El repositorio incluye modo demo sin cuentas, arquitectura documentada, auditoría de privacidad y CI multiplataforma.

## Presentación de 30 segundos

> Zoom2TXT nació de un problema que yo mismo tenía cada semana. El proceso completo exigía entre 15 y 18 acciones y era fácil repetir o perder trabajo. Lo convertí en un flujo de escritorio recuperable: detecta cursos, elige el video correcto, conserva estados intermedios y entrega el TXT. Para que un reclutador pueda evaluarlo sin una cuenta institucional, añadí un modo demo totalmente sintético y una suite de 148 pruebas.
